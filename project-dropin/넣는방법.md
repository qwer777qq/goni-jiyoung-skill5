# 프로젝트에 넣는 방법

이 폴더의 내용 전체를 영상 프로젝트 최상위에 복사하세요. 숨김 폴더 `.jiyoung-video`도 포함합니다.

1. Codex는 AGENTS.md, Claude Code는 CLAUDE.md를 읽습니다.
2. 두 도구 모두 김지영프로_영상자동화.md 한 파일을 편집 기준으로 사용합니다.
3. 이미 AGENTS.md/CLAUDE.md가 있다면 덮어쓰지 말고 “김지영프로_영상자동화.md를 읽고 적용한다”는 문단을 기존 파일에 추가하세요.
4. 새 대화에서 “프로젝트 지침을 읽고 김지영 스킬5로 이번 영상을 편집해 줘”라고 요청하세요.

공통 MD만 별도 프로젝트 자료로 등록해도 편집 지침으로 사용할 수 있습니다. 실제 자동화 실행에는 로컬 미디어·Python·편집기가 필요합니다. 앱 연결이 없는 웹 대화에서는 편집표·자막 초안·인수 지침까지만 만들 수 있습니다.
